# Proposition de bullet CV — V4

Cette proposition reste dans le projet ; aucun CV n'a été modifié.

> Built and evaluated a reproducible RGB-D policy robustness benchmark in MuJoCo: 12 behavior-cloning policies, matched data and budgets across three seeds, 2,400 held-out rollouts, paired uncertainty estimates, failure diagnostics, and a standalone checkpoint demo.

Portée : un cube, un bac, une consigne fixe, 79 démonstrations retenues sur 80 collectes, perturbations synthétiques appliquées aux points après échantillonnage. Les augmentations ne montrent pas de gain global observé. Aucun robot réel ni transfert sim-to-real évalué.
